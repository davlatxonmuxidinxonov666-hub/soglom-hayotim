# Sog'lom Hayot

Kaloriya hisoblagich (o'zbek taomlari bilan), qadam hisoblagich, suv va vazn kundaligi, mashg'ulotlar va sog'lom ovqatlanish rejasi. Android ilova, internetsiz ishlaydi.

- Nima yeganingizni yozing ("osh, achchiq-chuchuk va 2 ta somsa", "плов и 2 самсы") — ilova kaloriya, oqsil, yog' va uglevodni hisoblaydi.
- 290 dan ortiq taom: o'zbek taomlari, non, go'sht, sut mahsulotlari, meva, ichimliklar, fast-fud; o'z taomingizni qo'shish mumkin.
- Fonda ishlaydigan qadam hisoblagich, masofa va sarflangan kaloriya.
- Kunlik me'yor (Mifflin–San Jeor), maqsad: ozish / saqlash / vazn olish.
- Tillar: o'zbekcha, ruscha, inglizcha.
